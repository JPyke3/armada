LOCAL COMPATIBILITY ONLY

  patches/0105b-drm-panel-il97680a-linux-7.2-compat.patch

Do not send this third patch upstream. It changes only the orientation
helper name from drm_of_get_panel_orientation to of_drm_get_panel_orientation,
which is the API provided by Linux 7.2.6. This is the sole difference in
the tested driver C source versus the mailing-list candidate.

No later patch changes the IL97680A driver or binding. The Nova brightness
curve, panel VRR/video-mode changes and Duo ordered supply handling are
removed. Both variants use the candidate's fixed 60/120 Hz command modes,
raw DCS brightness and per-variant bulk supplies. The AVR patch retains
only host infrastructure; neither panel advertises VRR.

BUILD AND TEST

From the Armada repository root:

  env -u FAST bash packages/build-local.sh kernel

Use the normal test-image workflow to deploy the resulting package.
Do not use FAST=1 with the direct kernel build script: it reuses the old
patched tree. No kernel or image has been installed by this preparation.

Test cold boot, 60/120 Hz mode switching, low/mid/high/zero brightness,
blank/unblank and repeated suspend/resume on both devices. This is a
candidate test, not validation of the previous Armada panel extensions.

The current Nova node supplies only vddio plus an unused avdd mapping;
the remaining four driver supplies use dummy regulators. Its existing
wiring is preserved. A successful boot cannot validate the proposed
five-supply binding: resolve the physical supply mapping before a final
submission. The Duo bottom-panel node passed the earlier binding check.

VALIDATION

All 262 kernel patches and the vendor DTS patches apply with fuzz disabled;
all kernel patch hunks are consumed. The two mailing-list patches import
with git am onto the mainline base and pass strict checkpatch with zero
diagnostics. Driver, binding and both board sources match the plain
candidate already compiled and checked earlier. Earlier checks included
ARM64 W=1 panel object builds, both DTB builds and dt_binding_check.
No full image build or runtime hardware test has been performed here.
